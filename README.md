# Cafe Website ☕

A responsive cafe website built using HTML, CSS, and Bootstrap.

## Features
- Home Page
- About Us Section
- Menu Section
- Services
- Special Offers
- Gallery
- Contact Us
- Responsive Design

## Technologies Used
- HTML5
- CSS3
- Bootstrap 

## Project Purpose
This project was created to practice front-end web development and build a modern cafe website with an attractive user interface.
